# Changelog

## 0.7.0
- **Real code intelligence.** Python: Jedi with the standard library, the project `.venv` and a bundled discord.py source. JavaScript / TypeScript: TypeScript language service in a Web Worker with bundled discord.js v14, Node.js and ES2022 typings. Hover docs and TypeScript type errors.
- New default fonts (Source Code Pro, Noto Sans), a font picker with 5 code fonts, 3 interface fonts and an optional ligature switch; Vazirmatn fallback for Arabic/Persian text.
- New application icon with a transparent background.
- Light mode switch to turn the heavy intelligence engines off.

## 0.6.0
- Ready-made modules (Moderation, Server & user info, Welcome), Components builder (button / select menu / modal).
- Discord-bot linter with quick fixes (missing `await`, blocking `time.sleep` / `requests`, missing Message Content intent).
- Bot outline panel, personal snippets, check-all-files, Zen mode, hover docs.

## 0.5.0
- Modern floating-panel UI, SVG icons, responsive layout (explorer hides / becomes an overlay on narrow windows), resizable explorer and terminal.
- Real interactive terminal (PTY) next to the Output tab, hidden by default.
- Test Chat for discord.js, 18 themes with a visual picker, word-wrap toggle.

## 0.4.0
- Project search and replace, `.env` manager, invite link and intents calculator, syntax diagnostics, format document, Git actions, welcome screen with recent projects, `cordium <folder>` from the shell.

## 0.3.x
- Fixed the blank window (frontend assets were not embedded), WebKit start-up workarounds, auto-save, file operations from the explorer, collapsible terminal, click-through tracebacks.

## 0.2.0
- Command palette, snippets, slash command and embed builders, Test Chat for discord.py.

## 0.1.0
- First version: Discord-styled editor, file explorer, bot templates, console.
