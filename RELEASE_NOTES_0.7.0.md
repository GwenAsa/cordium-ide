# Cordium 0.7.0

**Code intelligence, new fonts, new icon.**

- Python autocomplete and hover powered by Jedi: standard library, your `.venv`, and the full discord.py source.
- JavaScript / TypeScript autocomplete, hover and type errors powered by the TypeScript language service with complete discord.js v14 typings.
- New default fonts (Source Code Pro / Noto Sans), font picker, ligatures off by default.
- New transparent application icon.
- Light mode switch (palette: *Toggle smart code intelligence / light mode*) to save RAM.

Install: `sudo apt install ./Cordium_0.7.0_amd64.deb` (needs `python3`; Node.js 20.6+ for discord.js bots).

Memory use (approx.): 350 MB idle, 560 MB with Python intelligence, 630 MB with JS/TS intelligence.
